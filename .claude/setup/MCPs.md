# Instructions on how to setup MCP

## Jira MCP
- we use Jira https://bigbongo.atlassian.net/jira/software/projects/SCRUM/boards/1
- we use MCP with atlassian jira: https://support.atlassian.com/atlassian-rovo-mcp-server/doc
  s/getting-started-with-the-atlassian-remote-mcp-server/
- you need to get permissions to run MCP, but this doesn't work with `--dangerously-skip-permissions`. You need to run regular `claude` command without flags to trigger the permission prompt
